# 🗄️ Database Development & Use

> A hands-on course repository for learning relational and non-relational database concepts from a software developer's perspective — using Python and SQL.

---

## 📚 Course Overview

This repository contains coursework, projects, and code examples for **Database Development and Use**. The course covers the full lifecycle of working with databases: designing data models, writing efficient queries, building Python-powered applications, and applying security best practices.

By the end of this course, you'll be comfortable working with both relational (SQL) and non-relational (NoSQL) databases and understand when and why to use each.

**Prerequisite:** CSD 205 – Introduction to Programming with Python

---

## 🎯 What You'll Learn

| Area | Topics Covered |
|------|---------------|
| **Data Modeling** | Relational vs. non-relational structures, key/value pairs, table design |
| **SQL** | Creating, reading, updating, and deleting records; query optimization |
| **Python Integration** | Connecting to and interfacing with database systems using Python |
| **Security** | Access controls, data validation, and risk mitigation |
| **NoSQL** | Defending and implementing non-relational database structures |

### Course Objectives

By successfully completing this course, students will be able to:

1. Compare and contrast relational and non-relational database structures
2. Design data models that accurately reflect business requirements
3. Defend the use of non-relational database structures
4. Use Python to connect and interface with both database types
5. Create, update, delete, and query records across database systems
6. Apply industry best practices for access controls and data validation
7. Identify methods to mitigate security risks
